# Habit Challenge

Веб-приложение для отслеживания привычек с ежедневными отметками, сериями выполнения, наградами и испытаниями.

Учебный проект по разработке серверной части интернет-ресурса. Бизнес-логика реализована на PHP с использованием архитектуры **MVC**.

## Возможности

- Несколько независимых челленджей с собственными стриками и историей отметок.
- Одна отметка в день для каждого челленджа.
- Ежедневная награда: **10 монет** за первую отметку дня на аккаунте; дополнительные **50 монет** за каждые семь последовательных дней активности.
- Общее ежедневное испытание с наградой в монетах.
- Рамки стрика, меняющие оформление по мере прогресса.
- Отдельная страница истории: отметки, выполненные испытания, награды и фильтр по челленджам.
- Локальная админ-панель: сброс отметок и испытаний, назначение индивидуального задания, тестовый предпросмотр стриков без изменения реальной истории.

## Локальный запуск

Понадобятся **Docker Desktop** и **Git**.

```bash
git clone https://github.com/misterlolipop04/habit-challenge.git
cd habit-challenge
docker compose up -d --build
```

При первом запуске MySQL автоматически выполняет `database/init.sql`: создаёт основные таблицы и набор ежедневных испытаний. Для **новой пустой базы** затем создай демонстрационный аккаунт и примени миграции:

```bash
docker compose exec -T db mysql --default-character-set=utf8mb4 -uuser -ppassword daily_rewards -e "INSERT IGNORE INTO users (id, challenge_name) VALUES (1, 'My Challenge');"

docker compose exec -T db mysql --default-character-set=utf8mb4 -uuser -ppassword daily_rewards < database/admin_user_task_overrides.sql

docker compose exec -T db mysql --default-character-set=utf8mb4 -uuser -ppassword daily_rewards < database/multi_challenges.sql
```

> Эти шаги нужны для чистой установки. Существующую базу данных с историей активности повторно инициализировать не следует.

После настройки доступны:

- **Главная:** http://localhost:8081/
- **История:** http://localhost:8081/history/

### Админ-панель

Для включения локальной админ-панели выполни:

```bash
bash scripts/setup-admin.sh
```

Скрипт запросит пароль администратора, сохранит его хеш в локальном `.env` и перезапустит веб-контейнер.

**Админ-панель:** http://localhost:8081/admin/

Файл `.env` исключён из Git через `.gitignore`.

## Структура проекта

```text
app/
  controllers/   # Обработка запросов
  models/        # Бизнес-логика и работа с MySQL
  views/         # HTML/PHP-представления
admin/           # Точка входа админ-панели
history/         # Страница истории
database/        # SQL-инициализация и миграции
public/          # CSS
scripts/         # Настройка локального администратора
index.php        # Точка входа главной страницы
compose.yaml     # Контейнеры веб-сервера и MySQL
Dockerfile       # Образ PHP/Apache
```

## Границы проекта

На текущем этапе пользовательская часть работает с **одним демонстрационным аккаунтом (ID 1)** без регистрации и входа. Это локальный учебный прототип, **не готовый к публичному развёртыванию**.

Docker публикует веб-сервер только на `127.0.0.1:8081`; порт MySQL наружу не выставлен. В `compose.yaml` и `app/db.php` используются **тестовые пароли базы данных**: перед публикацией работающего сервиса их необходимо заменить и вынести в защищённую конфигурацию, а также добавить авторизацию пользователей и HTTPS.
