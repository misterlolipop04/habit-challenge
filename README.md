# Habit Challenge

Веб-приложение для отслеживания привычек с ежедневными отметками, стриками, наградами и испытаниями.

Учебный проект по разработке серверной части интернет-ресурса на **PHP** с архитектурой **MVC**.

## Возможности

- Несколько независимых челленджей со своими стриками и отметками.
- Одна отметка в день на челлендж; **10 монет** за первую отметку дня на аккаунте.
- Ещё **50 монет** за каждые семь последовательных дней активности аккаунта.
- Общее ежедневное испытание с наградой в монетах.
- Рамки стриков, которые меняются по мере прогресса.
- Отдельная страница полной истории активности с фильтром по челленджам.
- Локальная админ-панель: сброс отметок, назначение испытания конкретному пользователю и тестовый просмотр рамок стрика.

## Запуск с нуля

Требуется Docker Desktop и Git.

```bash
git clone https://github.com/misterlolipop04/habit-challenge.git
cd habit-challenge
cp .env.example .env
```

Открой **локальный** файл `.env` и задай собственные непустые значения `DB_PASSWORD` и `DB_ROOT_PASSWORD`. `DB_USER=habit_app` можно оставить. Этот файл не публикуется на GitHub.

```bash
docker compose up -d --build
```

На **новом томе MySQL** файл `database/init.sql` автоматически создаёт все необходимые таблицы, четыре испытания, пользователя **ID 1** и его первый челлендж. Ручной импорт миграций для чистой установки не нужен.

Открой:

- **Главная:** http://localhost:8081/
- **История:** http://localhost:8081/history/

### Админ-панель

Для локальной настройки пароля администратора:

```bash
bash scripts/setup-admin.sh
```

После настройки: http://localhost:8081/admin/

Скрипт сохраняет хеш пароля в локальном `.env`; сам пароль в репозитории отсутствует.

### Если уже есть база от предыдущей версии

Не удаляй том MySQL и не выполняй повторную инициализацию. Для существующей базы используй реальные действующие учётные данные в `.env` — смена переменных в Docker Compose **не меняет пароль уже созданного пользователя MySQL**. Ранние SQL-миграции в папке `database/` сохранены для обновления старых установок.

## Структура

```text
app/controllers/  # Контроллеры
app/models/       # Бизнес-логика, запросы к MySQL
app/views/        # Представления
admin/            # Вход в админ-панель
history/          # Страница истории
database/         # SQL и миграции
public/           # CSS
scripts/          # Локальная настройка администратора
index.php         # Главная точка входа
compose.yaml      # Сервисы Docker
```

## Безопасность и ограничения

Это локальный учебный прототип, не публичный сервис. Обычный интерфейс использует один демонстрационный аккаунт (ID 1) без пользовательской регистрации и авторизации. Веб-сервер Docker доступен только на `127.0.0.1:8081`; порт MySQL наружу не публикуется. Перед настоящим интернет-развёртыванием необходимы полноценная авторизация пользователей, HTTPS и отдельная конфигурация безопасности.
